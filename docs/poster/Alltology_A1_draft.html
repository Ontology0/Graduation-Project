01 / WHY IT MATTERS

어느 한쪽만 믿으면
틀릴 수 있다

검색한 문서도, 모델이 기억한 정보도 항상 정확하지는 않다.

기억은 맞고, 문서는 틀릴 때
기억 A · 정답≠문서 B · 오답

문서를 그대로 따르면 오답이 된다.

→ 기존 지식 유지가 도움

기억은 틀리고, 문서는 맞을 때
기억 A · 오답≠문서 B · 정답

기억을 무조건 강화하면 오답이 된다.

→ 올바른 문맥 수용이 도움

설명용 예시. 실제 추론에서는 정답을 알려주지 않고 내부 신호를 바탕으로 선택한다.

02 / OUR APPROACH

신호를 읽고, 필요한 개입을 선택한다

어텐션 헤드·은닉 표현 등에서 신호를 읽고, Routing으로 개입 여부·방향·강도를 선택한다.

별도 접근: 답변 분기를 비교하는 Packed

문서를 본 답변 ↔ 문서를 보지 않은 답변 → 분기 선택

두 분기를 한 입력 처리 호출에 담아 비교한다. Routing과의 결합은 후속 연구다.

One-pass Routing: 추론 중 신호로 개입을 결정하는 경로도 구현·분석한다.
Steering은 모델 가중치를 고정한 채 내부 활성값을 조절한다.
신호를 읽는 위치와 개입 위치는 구분하며, Router는 별도로 학습한다.

03 / WHAT WE OBSERVED

정답률 개선과 ‘맞히던 답 보호’를 함께 본다

ConFiQA-QA · 1,000개 질문 / 2,000개 입력 · 사실 정답 기준 정확 일치율(EM)

올바른 문맥(C+)에서의 변화
개입 전 대비 변화(%p) · 음수는 성능 저하

Router: 전체 개선과 함께
올바른 문맥의 성능 보호 기준을 충족했다.

Packed: 전체 정답률은 개선됐지만
올바른 문맥을 버리는 손상이 관찰됐다.

Router는 대상 ConFiQA 학습 fold의 정답으로 학습했고, Packed는 대상 라벨 없이 평가했다. 두 방법의 점수만으로 우열을 단정하지 않는다.
C+ 보호 기준(비열등): ΔEM의 95% 신뢰구간 하한 > −2%p. 하한은 Always −4.50, Router −0.60, Packed −9.50%p이며, 기준 충족이 C+ 개선 입증을 뜻하지는 않는다.

P8S 저장 행동 결과의 정책 평가(612질문): Router − Always = +0.82%p, 95% CI [−0.49, +2.21]. 유의한 우위는 미확인.
