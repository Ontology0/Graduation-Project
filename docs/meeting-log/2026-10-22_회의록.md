**2. Steering 관련 논문 리뷰**
- 10월 27일 교수님 미팅 전까지 팀원별로 Steering 관련 논문을 2편씩 리뷰하기로 함
- 논문별 핵심 아이디어, 개입 위치와 방식, 사용 신호, 추론 비용, 팀 연구와의 연결점을 중심으로 정리하기로 함
- 중복 논문을 줄이고 다양한 방법을 검토할 수 있도록 각자 선정한 논문을 사전에 공유하기로 함

**3. 10월 15일 후속 연구 과제 계속 진행**
- 10월 15일 회의에서 정한 Routing 및 One-pass Routing 고도화 작업을 계속 진행하기로 함
- Router의 행동 종류와 개입 강도(ρ)를 확장하여 안정적인 설정을 탐색하기로 함
- hidden state와 중간 레이어 entropy 등 내부 신호를 활용한 One-pass Routing 가능성을 검토하기로 함
- 기존 Router, One-pass Router, Router를 제외한 구성의 성능과 추론 비용을 비교하기로 함
- 첫 토큰과 로그 확률을 이용한 분기 선택 규칙의 근거를 분석하고, 외부 벤치마크 적용을 위한 실험 자료 정리를 이어가기로 함

- 수업을 대체하여 팀별로 자유롭게 회의를 진행하고 그 내용을 회의록으로 작성하기로 함
- 지금까지 작성한 전체 회의록과 10월 21일~26일 프로젝트 활동 내용이 저장소에서 확인 가능하도록 정리하기로 함

**5. GitHub Repository URL 제출**
