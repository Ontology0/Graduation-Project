## 🗓 2026-09-29 (화) 교수님 면담

> 시간 12:30 ~ 14:30 ㅣ 장소 진선미관 교수님 사무실 ㅣ 작성자 이다영

참석: 황의원 교수님, 박은주(석사과정), 박세령, 이다영, 손현경 — 총 5명

### 📌 면담 전 준비
- attention head 단위 내부 신호 분석과 5-fold 검증 결과 정리
- 라벨 사용량을 줄인 head 벡터의 4-state 판별 성능 확인
- 상태별 개입 강도와 Always Steering의 답변 성능 비교
- attention weight, value 반영 출력, 벡터 크기·방향 비교

### 💡 논의 내용

**1. Attention head 기반 상태 판별**
- 모델의 기존 지식과 문맥의 정오를 구분하는 내부 신호를 attention head 단위로 분석하고 5-fold 검증을 수행함
- 개발 단계 라벨 사용량을 20%로 줄여 찾은 head 벡터에서도 학습된 분류기의 상태 판별 성능이 약 0.61 Macro-F1로 유지됨
- 적은 라벨로도 유용한 신호를 찾을 가능성을 확인함

**2. 상태 판별과 steering 효과의 분리**
- 상태를 잘 구분하는 것이 실제 답변 성능 개선으로 바로 이어지지는 않음
- 개입 강도를 높이면 올바른 문맥을 활용하던 답변도 손상됨
- 상태에 따라 개입 강도를 선택하는 방식도 현재 기준 설정보다 뚜렷한 개선을 보이지 않음
- 상태 판별 신호와 실제 답변을 조절하는 steering 방향을 분리하여 설계하는 방안을 논의함

**3. Attention 내부 신호 분석**
- attention weight 자체보다 value가 반영된 출력에서 문맥 관련 신호가 더 뚜렷하게 나타남
- 벡터의 크기보다 방향 정보가 중요한 것으로 나타남
- 단순 스칼라·임계값 방식의 한계를 보완하고 벡터 방향과 다차원 정보를 활용하는 방법을 검토하기로 함

**4. 입력별 동적 개입**
- 데이터셋 전체에 동일한 head를 고정하기보다 입력별 내부 신호에 따라 개입할 head를 동적으로 선택하는 방법을 검토하기로 함
- 평균 차이 벡터를 더하는 방식에 한정하지 않고 head 출력이나 value의 특정 성분을 조절하는 방법도 탐색하기로 함
- 관련 연구로 SpARE 등을 추가 검토하기로 함

**5. 라벨 사용 범위**
- 사전 분석과 steering 방향 추정에는 소량의 라벨을 허용함
- 실제 추론에서는 정답 또는 실제 지식·문맥 상태 라벨을 사용하지 않기로 함
- 전체 과정에서 라벨을 전혀 사용하지 않는 방식과 구분하여 연구 목표와 실험 조건을 명시하기로 함

### ✅ 결정 사항 및 방향
- 소량 라벨 조건에서 attention head 기반 4-state 판별 신호를 계속 검증함
- 상태 판별 신호와 답변 행동을 바꾸는 steering 방향을 분리하여 설계함
- attention weight보다 value가 반영된 출력과 벡터 방향·다차원 정보를 중심으로 분석함
- 입력별 내부 신호에 따라 개입할 head를 동적으로 선택하는 방법을 검토함
- head 출력 또는 value의 특정 성분을 조절하는 방법과 SpARE 등 관련 연구를 탐색함
- 라벨은 개발 단계의 사전 분석·방향 추정에만 소량 사용하고 실제 추론에서는 사용하지 않음
