## 🗓 2026-09-22 (화) 교수님 면담

> 시간 12:30 ~ 14:00 ㅣ 장소 진선미관 교수님 사무실 ㅣ 작성자 이다영

참석: 박세령, 손현경, 이다영, 황의원 교수님, 박은주(석사과정) — 총 5명

### 📌 면담 전 준비
- 질문과 문맥을 함께 입력한 조건에서 레이어별 내부 표현 분석
- FFN 기반 PKS와 hidden vector 전체를 사용한 상태 판별 성능 비교
- baseline 행동 그룹과 hidden representation 평균 차이를 이용한 steering 실험
- 단일 패스 조건부 routing 구조와 데이터셋 확장 순서 검토

### 💡 논의 내용

**1. 레이어별 기존 지식·문맥 신호**
- 질문과 문맥을 함께 입력한 상태에서 레이어별 내부 표현을 분석함
- 모델의 기존 지식 관련 정보는 비교적 앞쪽 레이어부터 구분되었고, 문맥 관련 정보는 중·후반 레이어에서 더 뚜렷하게 나타나는 경향을 확인함
- 하나의 레이어에서 모든 상태를 판단하기보다 앞쪽과 뒤쪽 레이어의 역할을 나누어 개입 여부를 판단하는 구조를 계속 검토하기로 함

**2. PKS와 hidden representation 비교**
- ReDeEP의 FFN 기반 PKS 신호를 추가로 검증함
- PKS처럼 내부 정보를 하나의 값으로 압축한 신호보다 hidden vector 전체를 이용했을 때 내부 지식 상태가 더 잘 구분됨
- PKS를 주요 신호로 사용하기보다 hidden representation에 존재하는 정보를 직접 활용하기로 함

**3. Steering direction 실험**
- baseline에서 나타난 모델 행동을 기준으로 그룹을 나누고 hidden representation의 평균 차이로 steering direction을 구성했을 때 답변 성능이 개선됨
- 모델 내부의 특정 방향에 개입하는 것이 실제 답변 행동 변화로 이어질 가능성을 확인함
- 현재 실험은 K/C 상태나 모델 행동을 비교적 정확히 아는 조건이므로, 실제 추론 환경에서 이 정보를 추정하는 방법이 핵심 과제로 남음

**4. 정답 라벨 없는 개입 판단**
- 메소드의 핵심을 정답 라벨 없이 개입 필요 여부와 steering 방향을 결정하는 방법으로 구체화함
- 학습된 probe의 weight와 feature attribution을 분석하여 특정 attention head 또는 subspace에 관련 신호가 집중되는지 확인하기로 함
- 가능하다면 별도의 K/C 정답 라벨 없이 사용할 수 있는 내부 신호로 대체하는 방안을 검토함

**5. One-pass 조건부 구조와 routing 기준**
- 한 번의 입력 처리 과정에서 앞쪽 레이어는 빠르게 판단 가능한 사례를 처리하고, 불확실한 사례는 중·후반 레이어에서 문맥 정보까지 확인한 뒤 steering 여부를 결정하는 구조를 실험함
- 현재는 가능성을 확인한 단계이며, 단순 상태 분류보다 실제 개입 시 성능이 좋아질 사례를 예측하도록 routing 기준을 고도화하기로 함

**6. 데이터셋 확장과 후속 방법**
- 데이터셋 확장은 바로 진행하지 않고 현재 데이터셋에서 steering direction, 개입 레이어, routing, 주요 hyperparameter를 먼저 정립하기로 함
- 동일한 pipeline을 다른 데이터셋에 적용하여 일반화 성능을 검증하기로 함
- 단일 steering vector를 더하는 방법뿐 아니라 projection과 representation space 변환을 이용한 선행 연구도 검토하기로 함

### ✅ 결정 사항 및 방향
- 기존 지식과 문맥 신호가 나타나는 레이어의 차이를 활용하여 앞·뒤 레이어의 역할을 분리함
- 주요 판별 신호는 PKS보다 hidden representation 전체를 직접 활용하는 방향으로 전환함
- 정답 라벨 없이 개입 필요 여부와 steering 방향을 결정하는 방법을 연구의 핵심으로 설정함
- probe weight와 feature attribution을 분석하여 attention head 또는 subspace 수준의 내부 신호를 탐색함
- routing 기준은 상태 분류가 아니라 실제 개입 이득을 예측하도록 고도화함
- 현재 데이터셋에서 방법과 hyperparameter를 정립한 뒤 다른 데이터셋으로 일반화 성능을 검증함
