## 🗓 2026-09-15 (화) 교수님 면담

> 시간 12:30 ~ 14:00 ㅣ 장소 진선미관 교수님 사무실 ㅣ 작성자 이다영

참석: 박세령, 손현경, 이다영, 황의원 교수님, 박은주(석사과정) — 총 5명

### 📌 면담 전 준비
- 질문만 입력해 학습한 내부 지식 판별기의 실제 입력 조건 성능 점검
- ReDeEP의 PKS 신호와 CAST의 조건부 개입 구조 검토
- grand STD와 projection STD 비교 결과 및 스티어링 레이어 조합 정리
- 답변 형식, 최대 생성 토큰, Gold-free 범위에 대한 실험 기준 정리

### 💡 논의 내용

**1. 실제 입력 조건에서의 내부 지식 판별**
- 질문만 입력한 상태에서 학습한 내부 지식 판별기를 질문과 문맥이 함께 주어지는 실제 실험 환경에 적용하자 성능이 하락함
- 실제 입력 조건에서도 모델의 내부 지식 상태를 판별할 수 있는 신호를 다시 검토하기로 함

**2. PKS 신호와 조건부 개입 구조**
- ReDeEP에서 제안한 FFN 기반 신호인 PKS를 내부 지식 판별에 활용하는 방안을 논의함
- CAST를 참고하여 앞쪽 레이어에서 개입 필요 여부를 판단하고 뒤쪽 레이어에서 행동을 조정하는 구조를 검토함
- 별도의 사전 추론 없이 동작하는 구조를 목표로 하되, 신호의 유효성과 구현 가능성은 후속 실험과 원문 검토를 통해 확인하기로 함

**3. 스티어링 강도와 레이어 역할**
- grand STD와 projection STD는 모두 논리적으로 가능한 설계라는 의견을 받음
- 비교 실험을 통해 적합한 방식을 선택하고, 개입 시점과 레이어 조합도 함께 검토하기로 함
- 신호를 읽는 레이어와 실제 개입하는 레이어의 역할을 구분하여 실험하기로 함

**4. 프롬프트와 생성 토큰 기준**
- 프롬프트는 모델의 지식 선택을 미리 유도하지 않으면서 답변 형식만 통제하도록 단순하게 구성하기로 함
- 최대 생성 토큰은 192를 기준으로 실험하기로 함
- 답변 절단 여부는 마침표 유무가 아니라 생성 토큰이 상한에 도달했는지를 기준으로 확인하는 방안을 논의함

**5. Gold-free 범위와 연구 목표**
- Gold-free의 범위는 배포·추론 단계에서 정답 라벨을 사용하지 않는 것으로 정리함
- 최종 연구 목표에는 논문 작성뿐 아니라 내부 지식 관련 신호 탐색, 조건부 스티어링 구현, 답변 성능과 계산 비용 검증을 포함하기로 함

### ✅ 결정 사항 및 방향
- 질문과 문맥이 함께 주어진 실제 입력에서 유효한 내부 지식 신호를 다시 탐색함
- PKS와 CAST 구조를 검토하되, 별도의 사전 추론이 없는 조건부 개입 구조의 구현 가능성을 우선 확인함
- grand STD와 projection STD를 비교하고, 신호 판독 레이어와 개입 레이어를 분리하여 실험함
- 프롬프트는 지식 선택을 유도하지 않고 답변 형식만 제한함
- 최대 생성 토큰은 192로 설정하고 토큰 상한 도달 여부로 절단 가능성을 판단함
- Gold-free는 배포·추론 단계에서 정답 라벨을 사용하지 않는 조건으로 정의함
