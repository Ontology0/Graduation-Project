### 📌 면담 전 준비

### 💡 논의 내용

**1. Always Steering에서 Routing 중심으로 전환**
- Always Steering은 잘못된 문맥의 영향을 줄이는 과정에서 올바른 문맥을 활용하는 성능도 손상시키는 문제가 있었음
- 학습 기반 Router는 이러한 손상을 상대적으로 줄이면서 전체 성능을 개선할 가능성을 보임
- 연구를 Routing 중심으로 발전시키고, 개입 행동의 종류와 강도(ρ)를 다양하게 조정하며 각 선택의 근거를 분석하기로 함

**2. One-pass Routing 고도화**
- 학습 단계에서는 여러 개입 행동의 결과를 활용하더라도 실제 추론에서는 내부 신호만으로 행동을 선택하는 구조를 검토함
- attention head의 hidden state와 중간 레이어의 entropy 등 추가 신호를 활용하기로 함
- 기존 Router와 성능 및 추론 비용을 비교하기로 함

**3. 프롬프트 기반 확신도와 Steering 통합**
- 문맥이 있는 분기와 없는 분기의 첫 토큰 및 로그 확률을 비교하는 방식에서 성능 개선 가능성을 확인함
- 일부 데이터셋에서는 올바른 문맥을 활용하는 성능이 하락하는 문제가 있었음
- 해당 방법을 선택적 구성 요소로 두고 Routing을 제외한 경우 등도 비교하기로 함
- 첫 토큰 비교와 분기 선택 규칙이 효과적인 이유를 분석하기로 함

**4. 외부 벤치마크 비교**
- 최종 방법을 확정한 뒤 외부 벤치마크에서 기존 연구와 비교하기로 함
- 자체 P8S 데이터셋에 다른 방법을 구현하기보다 기존 연구가 사용한 데이터셋에 팀의 방법을 적용하는 방향을 우선함
- 공정한 hyperparameter 조정과 비교 실험으로 기존 방법 대비 개선 폭을 확인함
- 각 구성 요소의 필요성을 뒷받침할 분석을 추가하기로 함

**5. KSC 논문 제출**
- attention head 기반 지식–문맥 4-state 판별 연구를 국내 학회 KSC에 별도로 정리하여 제출하기로 함
- 해외 학회 제출을 목표로 하는 Steering 연구와 구분함
- 소량 라벨 조건의 4-state 판별 성능 평가를 중심으로 논문을 구성함
- 제출 전에 논문 파일과 제출 페이지를 지도교수님께 공유하여 최종 확인을 받기로 함
- 10월 14일 기준 교수님 검토를 받아 제출을 준비 중임

### ✅ 결정 사항 및 방향

- 개입 행동과 강도(ρ)를 확장하고 Router의 선택 근거를 분석함
- 실제 추론에서는 내부 신호만으로 행동을 선택하는 One-pass Routing을 고도화함

- 최종 방법 확정 후 기존 연구의 데이터셋에서 공정한 비교 실험과 구성 요소 분석을 수행함
- 4-state 판별 연구는 Steering 연구와 구분하여 KSC에 제출함
